# Анализ конфиденциальных данных системы «Медикаменте»

## I. Выявленные конфиденциальные данные

### Персональные данные пациентов (PII - Personally Identifiable Information)

**Базовые персональные данные:**

- **ФИО** (Фамилия, Имя, Отчество) - категория: ПДн
- **Дата рождения** - категория: ПДн
- **Телефон** - категория: ПДн
- **Электронная почта** - категория: ПДн

**Расширенные персональные данные:**

- **Адрес прописки** - категория: ПДн
- **Место работы/учёбы** - категория: ПДн
- **Хронические заболевания** - категория: Медицинские данные (особая категория)

### Медицинские данные (PHI - Protected Health Information)

**Медицинские карты:**

- **Диагнозы** - категория: Медицинские данные
- **Результаты анализов** - категория: Медицинские данные
- **Заключения специалистов** - категория: Медицинские данные
- **История лечения** - категория: Медицинские данные
- **Медицинские изображения** (сканы, рентген) - категория: Медицинские данные

### Финансовые данные

**Платежная информация:**

- **Суммы платежей** - категория: Финансовые данные
- **История платежей** - категория: Финансовые данные
- **Договоры с пациентами** - категория: ПДн + Финансовые данные
- **Данные ККМ** (чеки, транзакции) - категория: Финансовые данные

### 4. Данные сотрудников

**Кадровые данные:**

- **ФИО сотрудников** - категория: ПДн
- **Зарплаты** - категория: Финансовые данные
- **Кадровый учёт** - категория: ПДн

### Данные, не учтённые во внутренних системах

**Критические пробелы в учёте:**

1. **Логи доступа к файлам** - отсутствует аудит доступа к Excel-файлам и сканам
2. **История изменений данных** - нет версионирования файлов
3. **Метаданные файлов** - не учитываются даты создания, изменения, авторство
4. **Временные файлы** - Excel создаёт временные файлы, которые могут содержать конфиденциальные данные
5. **Кэш приложений** - 1С и Excel могут хранить данные в кэше
6. **Резервные копии** - не указано, как хранятся бэкапы файлов
7. **Электронная почта** - Exchange Mail Server может содержать переписку с ПДн
8. **Сетевой трафик** - данные передаются по локальной сети без шифрования
9. **Печатные документы** - физические копии медицинских карт не учтены
10. **Мобильные устройства** - если сотрудники используют личные устройства, данные могут быть не учтены
11. **Внешние носители** - USB-накопители, диски с данными пациентов
12. **Данные в оперативной памяти** - при работе с файлами данные остаются в RAM
13. **Журналы событий системы** - Windows Server логи могут содержать ПДн
14. **Данные интеграции** - данные, передаваемые между 1С:Бухгалтерия и 1С:Торговля
15. **Данные ККМ** - информация о транзакциях может содержать ПДн

## II. Классификация по уровню конфиденциальности

**Уровень 1 - Критически конфиденциальные (требуют максимальной защиты):**

- Медицинские диагнозы
- Результаты анализов
- История лечения
- Хронические заболевания

**Уровень 2 - Высококонфиденциальные:**

- ФИО + Дата рождения
- Адрес прописки
- Финансовые данные (платежи, договоры)

**Уровень 3 - Конфиденциальные:**

- Телефон
- Электронная почта
- Место работы/учёбы

**Уровень 4 - Внутренние данные:**

- Данные сотрудников (для внутреннего использования)
- Учёт ТМЦ

## III. Соответствие требованиям законодательства РФ

**Федеральный закон № 152-ФЗ "О персональных данных":**

- ✅ Требуется согласие на обработку ПДн
- ❌ Отсутствует политика обработки ПДн
- ❌ Нет технических мер защиты ПДн
- ❌ Отсутствует назначение ответственного за обработку ПДн

**Федеральный закон № 323-ФЗ "Об основах охраны здоровья граждан":**

- ✅ Медицинская тайна должна соблюдаться
- ❌ Нет разграничения доступа к медицинским данным
- ❌ Отсутствует аудит доступа к медицинским картам
