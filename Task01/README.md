## II. Ключевые выводы

**Критические проблемы:**

1. Отсутствие шифрования данных на диске
2. Отсутствие контроля доступа (все имеют доступ ко всем данным)
3. Отсутствие аудита доступа
4. Отсутствие защиты при передаче данных
5. Отсутствие защищённого резервного копирования

**Рекомендуемые меры:**

1. Внедрение BitLocker для шифрования файлового сервера
2. Настройка RBAC в Active Directory
3. Включение аудита доступа к файлам
4. Настройка TLS для всех соединений
5. Внедрение AIP для тегирования и защиты файлов
